Um jogo feito para a feira de tecnologia, com o intuito de apresentar e aplicar a IA em jogos, Neste jogo o usuário ele é uma cobrinha e o objetivo é pegar as frutas 
para acumular mais pontos, mais o diferencial desse jogo é que a Inteligência Artificial, ela está presente para Duelar contra o usuário, uma coisa curiosa é que o usuario
pode treinar a Ia para duelar contra ele, e o mesmo pode ver a Inteligência Artificial em pratica ou seja ela jogando.
